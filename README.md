# LayerNX CarOS

Ein Auto-Launcher für Android – kein Android-Fork, keine Custom-ROM, kein Root.
Läuft auf jedem Tablet oder Android-Autoradio ab **Android 10**, passt sich automatisch an Bildschirm und Leistung an und holt Apps vom Handy auf den Bildschirm.

> **Status:** Planungsphase. Es gibt noch keinen Code. Der vollständige Research- und Umsetzungsplan steht in [`docs/PLAN.md`](docs/PLAN.md).
